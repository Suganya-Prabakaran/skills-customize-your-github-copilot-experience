
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Create a Hangman game where players guess letters to reveal a hidden word before running out of attempts. You'll practice string manipulation, loops, conditionals, and random selection in Python.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description
Develop a command-line Hangman game that allows players to guess letters and tries to reveal a hidden word within a limited number of attempts.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses and show current progress in _ _ _ format
- Track incorrect guesses remaining and display them to the player
- End the game when the word is guessed or attempts are exhausted
- Display clear win/lose messages with the final word revealed
